# 100 Flag Challenge

A vertical, installable flag-guessing game designed for mobile and YouTube-style 9:16 screens.

## Game timing
- Easy: 4 seconds per flag
- Medium: 3 seconds per flag
- Hard: 2 seconds per flag

## Features
- 100 flags
- Start / Stop / Restart controls
- Horizontal countdown bar above the flag
- Installable PWA
- Portrait 9:16 layout

Open `index.html` through GitHub Pages to play and install the app.
